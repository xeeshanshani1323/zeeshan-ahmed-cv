# Dr. Zeeshan Ahmed — GitHub Pages CV

This is a responsive, static academic portfolio built from the supplied CV.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository**. A suggested name is `zeeshan-ahmed-cv`.
2. Upload `index.html`, `style.css`, and the `assets` folder from this ZIP to the repository root.
3. To enable the PDF download, copy your full CV PDF into `assets/` and name it exactly `Zeeshan_Ahmed_CV.pdf`.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your site will be available at a URL similar to:
   `https://YOUR-GITHUB-USERNAME.github.io/zeeshan-ahmed-cv/`

## Before publishing

- Replace the `ZA` avatar placeholder with your own professional photograph if desired.
- Replace the Google Scholar and LinkedIn `href="#"` placeholders with your real profile URLs.
- Check publication titles, publication status, dates, and skills carefully.
- The original CV contains personal contact details. Keep only the contact information you want publicly visible.
- GitHub Pages hosting is public. Do not upload identity-card images or other sensitive documents.

## Edit

Open `index.html` in VS Code or GitHub's editor to change text. Edit `style.css` to change colors, spacing, and layout. The site uses plain HTML and CSS; no build tools are required.
